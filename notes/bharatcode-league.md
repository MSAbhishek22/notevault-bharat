# BharatCode Build League — what this project is for

The BharatCode Build League is a hackathon for students, developers
and anyone building useful products with artificial intelligence.
You build an application, AI agent, chatbot or developer tool using
the BharatCode model API. The winner receives Rs 10,000, and also
gets an opportunity to interview for a paid software development
internship offering Rs 60,000 per month for three months. Winning
does not guarantee the internship — there is a separate interview
and selection process.

To take part: register on the official page, build with the
BharatCode model API, publish your source in a public GitHub
repository with a file named BharatCode.txt in its root, and submit
the repository link through the official event page before the
deadline: 10 November 2026 at 11:59 PM IST.

Judging considers GitHub stars, votes on the BharatCode website, and
the judges' own evaluation. Students can build with free student
access, subject to usage limits — Qwen free up to 10M tokens a day,
according to bharatcode.ai.

NoteVault Bharat is this repo's entry: ask your own notes, in your
language, answered by the BharatCode model API.
