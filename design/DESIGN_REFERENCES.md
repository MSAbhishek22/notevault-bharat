# Design references — NoteVault Bharat (inspected 2026-11-05)

See also `RESEARCH.md` for the full verified/unverified record. What was
actually inspected is stated per reference; nothing claims a full page
open that did not happen.

1. **Obsidian graph view** (same category: notes as a network) —
   https://clickup.com/blog/notebook-lm-vs-obsidian/ and
   https://community.obsidian.md/plugins/beautiful-graph — inspected via
   search-result text, 2026-11-05. What was inspected: descriptions of
   the graph view (nodes, links, tag/zoom filters) and the Beautiful
   Graph plugin (folder-aware palettes, distinct node roles, Folder Lens
   contours). Learning: a vault is legible when clusters are visible and
   colour-coded. Not copied: the dense force-directed hairball; our
   constellation is sparse and tag-sectored, with a list fallback.
2. **NotebookLM / Gemini Notebook** (same category: grounded Q&A over
   your sources, with citations) —
   https://clickup.com/blog/notebook-lm-vs-obsidian/ and
   https://www.prezent.ai/blog/notebooklm-alternatives — inspected via
   search-result text, 2026-11-05. What was inspected: the grounded-answer
   + citations model and the upload-and-chat interaction. Learning:
   citations are the trust mechanism. Not copied: cloud upload; ours is
   local-first, excerpts only, on ask.
3. **Beautiful Graph (Obsidian plugin)** (exceptional interaction/motion)
   — https://community.obsidian.md/plugins/beautiful-graph — inspected
   via search-result text, 2026-11-05. What was inspected: the plugin's
   visual systems (distinct node roles, six coordinated palettes, canvas
   controls, atmosphere). Learning: distinct visual roles per node type
   aid navigation. Not copied: the desktop-only plugin model.
4. **bharatcode.ai homepage** (product context) —
   https://www.bharatcode.ai/ — opened in full, 2026-11-05. What was
   inspected: flat-rate API framing, live capacity panel (Qwen 3.8 27B,
   DeepSeek V4.1 Flash), plans (students free Qwen up to 10M tokens/day),
   leaderboard. Learning: the "API is a shared utility" tone. Not copied:
   its marketing layout.
5. **NoteVault (own prior project, local)** — read in full locally
   (`design/DESIGN_CONSTITUTION.md`, `notes_agent/web.py`), 2026-11-05.
   What was inspected: the routing/budget ledger UI and its 3-column
   layout. Learning: the visible routing + budget panel works and is
   worth keeping. Not copied: the visual identity — deliberately replaced
   (see `PROJECT_DESIGN_REGISTRY.md`).

Typography note: no separate typography reference was opened; the type
choice (Georgia display + system sans with Noto Sans in the stack for
Devanagari) is justified in the constitution as an offline-safe,
bookish desk voice, not as a copy of a reference.
